# 按任务类型的整理变体

> 同样是"把对话变成字段"，调研、方案、测算、表达要抽的东西完全不同。
> 用法：把主笔记的三步法照做，只换下面这一段「抽取重点 + 提示词补充」。

## 变体 A｜调研类（访谈、竞品、现场）

| 抽取重点 | 为什么 |
|---|---|
| 谁说的、什么时候、在哪 | 没有这三样就不是一手证据 |
| 原话 vs 转述 | 转述会失真 |
| 结论 vs 观察 | 观察是数据，结论是判断 |
| 反例 | 有没有推翻你假设的说法 |

提示词补充：

```
重点抽取：① 每条证据的来源（人/时间/地点）；② 哪些是原话，哪些是转述；
③ 与我的假设相反的说法或数据，单独列一节；④ 我由此改变了哪个判断。
没有相反证据就写「未发现」。
```

## 变体 B｜方案生成类（概念、造型、方向）

| 抽取重点 | 为什么 |
|---|---|
| 我一共要过几轮、每轮条件变了什么 | 迭代痕迹 |
| AI 给了几个候选、各自差异 | 有没有真的发散 |
| 我淘汰了哪些、凭什么 | 取舍能力 |
| 我的方案和 AI 原稿差在哪 | 人的介入 |

提示词补充：

```
重点抽取：① 我提了几轮需求，每轮加了什么约束；② 每轮 AI 给了几个候选，
用一句话概括差异；③ 我淘汰了哪些、淘汰依据是什么；④ 最终方案与 AI 第一稿的差异清单。
不要评价哪个方案更好。
```

## 变体 C｜测算类（成本、造价、工期、产能）

| 抽取重点 | 为什么 |
|---|---|
| 每个数字的来源（谁报的价、哪份资料） | 没来源的数就是编的 |
| 假设 vs 实测 | 两者不能混 |
| 区间 vs 单点 | 早期多半是区间 |
| 哪个假设一崩、结论就垮 | 敏感性 |

提示词补充：

```
重点抽取：① 每个数字＋单位＋来源（问谁/查哪）；② 哪些是假设、哪些是实测；
③ 区间与单点分别标出；④ 哪个假设最脆弱、崩了会怎样。
抽不到来源的数字一律标「无来源」。
```

## 变体 D｜表达交付类（排版、文案、展板、视频）

| 抽取重点 | 为什么 |
|---|---|
| 给谁看、看多久 | 决定信息密度 |
| 我删掉了什么 | 取舍 |
| 第一眼要看到什么 | 层级 |
| 修改前后的差异 | 迭代 |

提示词补充：

```
重点抽取：① 目标读者与停留时长；② 我删掉了哪些内容、为什么；③ 第一眼/第一句要传达什么；
④ 修改前后的具体差异（不是"优化了排版"这种话）。
```

## 通用底线（四个变体都适用）

- 抽不到 = 写「未找到」，不许编。
- 不许出现评价词。
- `verify` 必须有外部锚；没有就写「未验证」。
- 整理完自己读一遍：**这像我说的，还是像 AI 说的？**
