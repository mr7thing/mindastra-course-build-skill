# 术语卡片库（外部引用笔记）

> 来源：https://chaojifeng.me/ai-terms/cards （访问日期 2026-11-04）
> 性质：外部站点，**只引用不搬运**；站点内容会变，引用时保留访问日期。
> 用途：学员写提示词、导师写 AI 工具笔记时查术语——把「模糊说法」换成「说清楚的说法」。

## 1. 它是什么

一个按职能分类的 AI 术语卡片库（产品 / 测试 / 技术管理 / UI 设计，每类约 8 张）。

每张卡片的形态是：**一句白话解释 + 同一个需求的两种说法**——
- 模糊说法：AI 只能猜；
- 用上这个词的说法：需求被说清楚。

末尾还有「用故事检验」的小题：给一个小故事选词，答对后给出提示词。

## 2. 怎么用在课程里

| 场景 | 用法 |
|---|---|
| 学员写 `ai_collab.intent` | 先查一次术语，把「帮我做个好看的页面」改成带具体约束的说法 |
| 学员写 `ai_collab.options` | 用准确术语要求「给我 3 个方案，分别偏 X/Y/Z」，而不是「多给几个」 |
| 导师写 `03_assets/notes.md` 的 AI 工具一节 | 引用具体卡片名，不复制正文 |
| 导师写 `task-type-variants.md` 的抽取提示词 | 同类术语对齐，避免每门课各造一套词 |

## 3. 引用纪律

1. **只给链接 + 一句判断**，不搬运卡片正文（与课程笔记的"不搬运"同规）；
2. 引用时标注**访问日期**与**卡片所属分类**（如「UI 设计类」），因为站点会随版本变化；
3. 用作「术语校准工具」，**不作为评分依据**——评判仍然只看证据与判断；
4. 站点内容属于外部资料，可信度按"二手来源"处理；与赛事原文冲突时，**赛事原文优先**。

## 4. 已知边界

- 分类是按互联网职能划分的（产品/测试/技术管理/UI），**不完全对应设计学院的专业划分**；
- 没有覆盖"设计研究/田野/制造工艺"这类设计项目特有的术语，那部分仍要课程自己建笔记；
- 站点是中文的；英文术语对照需要另找来源。
