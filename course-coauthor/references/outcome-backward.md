# 成果倒推：从简历行到关卡

> 课程的验收标准只有一条：**结课时，学员敢不敢把这个作品放进简历。**
> 写不出那一行，这门课还不该开。

## 1. 简历行模板

```
我在【真实对象】的【具体场景】里，用【方法 + AI】做出了【可展示 / 可使用 / 可验收的成果】，
并验证了【一条能被现实否掉的数】。
```

四要素缺一不可：

| 要素 | 缺了会怎样 |
|---|---|
| 真实对象 | 变成自选题，作品没有甲方，简历上写不出"给谁做的" |
| 具体场景 | 变成风格练习，只能说"我做了一个品牌"，说不出用在哪 |
| 可展示/可使用/可验收 | 变成过程作业，"我学了方法"不是成果 |
| 能被现实否掉的数 | 变成形容词作品，"提升了体验"无法验证 |

## 2. 三个领域的简历行示例

| 领域 | 简历行 |
|---|---|
| 实体产品 | 我为【宁海某户外用品厂】的天幕照明做了扣装结构与造型方案：在 9–10cm 灯体内实现 19/22/25mm 三档杆径适配，单件成本核到【X 元】、装配【N】道工序，并做出可打样样件。 |
| 空间在场 | 我为【长宁 13㎡ 青空间】做了场景与活动视觉系统：在 13㎡ 内支持 3 类品牌入驻切换，动线与 5 种活动形态经现场复核，改造成本核到【X 元/㎡】。 |
| 符号与表达 | 我为【甘德藏香】做了品牌识别与包装系统：从 4 类在地器物提炼符号，产出 VI + 3 款包装刀版，打样成本【X 元/件】，并在【N】家门店做了陈列验证。 |

## 3. 成果三层

| 层 | 判据（三条全中） | 谁来保证 |
|---|---|---|
| **L1 保底** | ① 有真实对象（不可是"某地""某品牌"）② 有过程证据（照片/记录/数据，非渲染图独苗）③ 有成品的可展示形态 | 课程必须保证所有人拿到 |
| **L2 中档** | 在 L1 之上：④ 经得起一次专业追问（问三个"为什么"不塌）⑤ 能进作品集/答辩 | 尽力的人 |
| **L3 高档** | 在 L2 之上：⑥ 可小规模实施/可打样/可创业（有一条能被真实世界验收的路径） | 少数学员 + 导师投入 |

**课程怎么写这三层**：不写"优秀/良好/及格"，写"结课时你手里会有哪个层次的东西、往上一层要多做什么"。这是"对提升负责"能落地的唯一方式——同一个班里有强有弱，分层让每个人都有一个够得着的目标。

## 4. 倒推四步

```
简历行
  → 证据：要写出这一行，学员必须拿得出哪 4–6 件证据？
  → 关卡：这些证据之间存在什么依赖？按依赖+最大风险排关卡
  → 字段：每件证据最省的提交形态是什么（见 field-design.md）
  → 工具：每个关卡有哪些可选方法（工具箱，不强制）
```

## 5. 反推会得到什么（常见错误）

从"知识点"正推，得到的是一串章节：品牌是什么 → 品牌策略 → VI 设计 → 包装 → 案例。学员读完知道很多，手里没有东西。

从"成果"倒推，得到的是一串关卡：先定真实对象（否则后面全是假设）→ 拿一手证据（否则方案是想象）→ 出方案并淘汰（否则只有一个答案）→ 验证约束（否则不知道能不能做）→ 交付（否则投不出去）。**关卡之间是依赖关系，不是章节顺序。**

## 6. 自检

- [ ] 简历行能一句话说完，且四个要素齐全
- [ ] L1 的三条判据，每一关的产出都在为它们服务
- [ ] 每一关都能回答"这一关的产出，会进入简历行的哪一部分"
- [ ] 至少有一关的产出是"能被现实否掉的数"（不能全是图）
